# Leave Management API

A Spring Boot REST API for submitting and managing employee leave requests in an
HR system. Clean layered architecture (Controller → Service → Repository) with an
in-memory `ConcurrentHashMap` store, so no database is required.

**Stack:** Java 17 · Spring Boot 3.3.5 (Web, Validation) · Maven · JUnit 5 / Mockito / MockMvc

## Data model

| Field | Type | Notes |
|---|---|---|
| `id` | Long | Generated by the server |
| `employeeId` | String | Required, 3–20 letters/digits/hyphens |
| `leaveType` | Enum | `CASUAL`, `SICK`, `EARNED`, `MATERNITY`, `PATERNITY`, `UNPAID` |
| `startDate` / `endDate` | Date | `yyyy-MM-dd`; `endDate` on or after `startDate` |
| `reason` | String | Required, 5–500 characters |
| `status` | Enum | `PENDING`, `APPROVED`, `REJECTED`, `CANCELLED` (new = `PENDING`) |

## Build and run

Requires JDK 17+ and Maven 3.9+ (or IntelliJ IDEA, which bundles Maven).

```bash
mvn spring-boot:run     # starts on http://localhost:8080 (dev profile seeds 3 records)
mvn clean package       # build the jar
```

Profiles: `dev` (default), `prod`, `test`. Run another profile with
`mvn spring-boot:run -Dspring-boot.run.profiles=prod`.

## API endpoints

Base URL: `http://localhost:8080`

| Method | Endpoint | Description | Success |
|---|---|---|---|
| GET | `/leaves` | All leaves (filters: `?employeeId=&status=`) | 200 |
| GET | `/leaves/{id}` | Get one by ID | 200 |
| POST | `/leaves` | Create | 201 + `Location` |
| PUT | `/leaves/{id}` | Update (full replacement, `status` required) | 200 |
| DELETE | `/leaves/{id}` | Delete | 204 |

Errors use a uniform JSON body (`timestamp`, `status`, `error`, `message`, `path`)
returned by a `@RestControllerAdvice` handler: `400` validation/bad input, `404`
not found, `409` overlap or update of a finalized leave.

On Windows PowerShell use `curl.exe`, or run the ready-made calls in
[`requests.http`](requests.http) from IntelliJ's HTTP client.

## Testing

```bash
mvn test
```

58 tests: service (Mockito), controller (`@WebMvcTest` + MockMvc), repository, and
a `@SpringBootTest` end-to-end CRUD flow. In IntelliJ: right-click `src/test/java`
→ **Run 'All Tests'**.
